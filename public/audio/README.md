Adhan notification audio
========================

Place locally licensed or personally provided Adhan files here:

- `allah-akbar.mp3` for the short alert sound.
- `adhan-full.mp3` for Dhuhr, Asr, Maghrib, and Isha notifications.
- `adhan-fajr.mp3` for Fajr notifications.

The app intentionally does not stream remote Adhan audio. If either full Adhan file is missing or cannot be played, Sabili falls back to the existing local short alert:

- `allah-akbar.mp3`
