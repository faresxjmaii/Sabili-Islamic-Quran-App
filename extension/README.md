# Sabili New Tab Extension

Build the Chrome/Edge/Brave extension:

```bash
npm run build:extension
```

Then load the generated `dist-extension` folder as an unpacked extension.

## Chrome

1. Open `chrome://extensions`.
2. Enable Developer mode.
3. Click Load unpacked.
4. Select `dist-extension`.
5. Open a new tab.

## Microsoft Edge

1. Open `edge://extensions`.
2. Enable Developer mode.
3. Click Load unpacked.
4. Select `dist-extension`.
5. Open a new tab.

## Brave

1. Open `brave://extensions`.
2. Enable Developer mode.
3. Click Load unpacked.
4. Select `dist-extension`.
5. Open a new tab.
